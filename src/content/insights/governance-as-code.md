# Governance as code

Architecture wikis, compliance spreadsheets, and review boards drift the moment they are written. The reason is simple: they are *descriptions* of a system that keeps changing, not *definitions* the system is built and measured against.

GSM turns governance into code. A Directive opens the scope, Norms make it measurable, and Ascriptions bind concrete obligations to real structures. The result is a single, versioned, machine-operable source of truth — the THINK layer that BUILD and RUN can both reference.

In this article we walk through the three-tempo grammar and show how it eliminates the reconstruction work that precedes every audit.
