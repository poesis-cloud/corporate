# Deterministic governance execution

Probabilistic models propose; governance disposes. The SIE Operator is the runtime that turns governed definitions into deterministic verdicts and dispatched effects.

We describe the five evaluation phases — frame resolution, type checking, rule evaluation, effector dispatch, and receptor derivation — and explain why sandboxed, step-limited execution matters for trustworthy enforcement.
