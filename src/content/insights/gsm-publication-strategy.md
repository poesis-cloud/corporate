# The Generative System Model

OpenTelemetry standardized how systems are observed. GSM aims to do the same for how systems are defined and governed.

This publication outlines the specification structure, the conformance program, and the path toward neutral stewardship — whether through CNCF sandbox incubation or a comparable standards body. The reference implementation holds no privileged status in the specification.
